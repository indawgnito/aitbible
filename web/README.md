# AIT Bible web

The Next.js site for reading the AIT Bible. It is a reader only: all translation data is generated by the pipeline in [../translator](../translator/README.md) and committed under `data/`.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). For a production build, `npm run build` then `npm run start`.

## What it shows

- **Chapter pages** with paragraphed text. Words of Jesus are red, God's purple, angels' blue.
- **Verse panel.** Click a verse number for its notes, the Greek with dictionary forms, and the King James Version for comparison.
- **Word choices** (at `/glossary`). The words where the text departs from the traditional English rendering, with the reason, the standard view and every verse where each is used.
- **Search** across the AIT text and the KJV.
- **Homepage examples** comparing a KJV verse with the AIT rendering.
- Dark mode, and a layout that works on a phone.

## Data

Everything in `data/` except `kjv/` is generated. Do not edit it by hand.

| File | Written by | Contents |
|---|---|---|
| `data/<book>.xml` | `pipeline.py export --run RUN --publish` | One book: translation, speaker segments, Greek words with lemmas, notes. Format: [../schema/ait-schema.md](../schema/ait-schema.md). |
| `data/glossary.json` | `build_glossary.py --run RUN` | Register entries that depart from tradition, with the verses where each is used. |
| `data/examples.json` | `build_glossary.py --run RUN` | Homepage examples, read from the served text so they always match it. |
| `data/kjv/*.json` | checked in | King James Version, public domain, for the comparison view. It follows a different Greek text, so some differences are textual. |

To update the site after a new run, run those two commands from `translator/` and commit the result.

## Layout

```
app/
  page.tsx                 home: examples, summary, book list
  vision/page.tsx          "How It Was Made"
  glossary/                the "Word choices" page
  search/, api/search/     search page and endpoint
  [book]/page.tsx          chapter grid for a book
  [book]/[chapter]/page.tsx  chapter text and notes
components/
  ChapterContent.tsx       text rendering and speaker colors
  VerseModal.tsx           notes, Greek and KJV for one verse
  TranslationNotes.tsx     collapsible notes under a chapter
  TranslationCarousel.tsx  homepage examples
lib/
  data.ts                  loads books and KJV
  xml-parser.ts            parses the AIT XML format
  glossary.ts              data for the "Word choices" page
  search.ts                verse search
  books.ts                 book names and chapter counts
```

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, next-themes, @xmldom/xmldom.

## Deploying

Any host that runs Next.js works. The book and chapter pages and the search endpoint render on the server, so a static export is not enough.
